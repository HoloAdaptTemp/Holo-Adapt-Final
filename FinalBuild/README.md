# Running
1. Run `glove_websocket_data.py` after setting COM port to the correct one
2. Run `Stars - HoloAdapt.exe`
3. Must be done on a 1920x1200 display with screen mirroring to the TV

# Scene Controls
Press button 1 for radial menu and rotate to select scene

1. Cancel: exits menu
2. Star Wars: no actions
3. Logo: no actions
4. Maze: rotate hand to rotate maze, flex 1 to jump, button 2 to reset (you might have to press it a lot)
5. Stars: rotate hand to rotate earth (roll), flex 1 to look the camera around. Activity is to find the north star by rotating the earth and finding the stationary star, then estimating the latitude of the user based on the angle from the horizon to the north star.
6. Engine: Flex 1 to rotate, flex 2 to explode, button 2 to enlarge
